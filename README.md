# Mindustry Schematics

Personal collection of Mindustry schematics organized by category for syncing directly with **Foo's Client** (`mindustry-antigrief/mindustry-client`).

## Sync with Foo's Client

1. Open Mindustry (Foo's Client).
2. Go to **Schematics → Schematic Browser → Repositories**.
3. Add `Eason0729/mindustry-schematic` and refresh.

All `.msch` files include embedded **names**, **descriptions**, and **tags/labels** so you can search and filter them directly inside the Schematic Browser.
